# 閒閒有事做：規劃文件

> 整理自 2026-10-12 和 Claude 的討論。

## 1. 起點：要解決什麼問題

> 我是一個腦袋一直在轉的人，有好多好多想做的事，但空下來的時候反而不知道該先做哪一件。

例如腦袋裡同時有這些事：

1. 鉤織＿皮克敏織圖
2. 鉤織＿蕃茄托特包織圖
3. 線上課程＿塔羅牌
4. 線上課程＿心理覺察
5. 線上課程＿日文
6. 線上課程＿英文
7. 任務＿整理衣櫃
8. 任務＿整理捐贈物資
9. 規劃＿日本打工度假
10. 規劃＿遠端工作
11. 任務＿更新履歷
12. ……還有很多很多

這些事**都不急**，所以排不出先後順序，有空的時候反而會選擇困難。

**需求：**

- 平常有新想法時，可以隨時、很快地加進清單
- 每件事要記錄大概需要多少時間
- 有空的時候，依照「現在有多少時間」幫我挑一件事

## 2. 定位

> **不是待辦清單，是想做清單。**
> 讓那些「總有一天想做」的事，在有空的時候真的被做到。

|  | 規劃型 App（Tiimo、Structured……） | 閒閒有事做 |
|---|---|---|
| 適合的事 | 有期限、必須做的事 | 想做、但不急的事 |
| 什麼時候打開 | 每天早上排行程 | 突然有空的時候 |
| 要你做的決定 | 每件事排在幾點 | 不用決定，讓扭蛋決定 |
| 沒做完的時候 | 行程落後，有壓力 | 沒差，下次再抽到就好 |

目標使用者：**腦袋停不下來、想做的事很多但都不急**的人。

## 3. 競品觀察

市面上**沒有**找到同時做到「隨機挑選 + 依現有時間篩選 + 依精力篩選 + 拆小步驟」的 App，大多只做到其中一兩項。

| 類型 | App | 重點 | 跟我們的差別 |
|---|---|---|---|
| 拆小步驟 | Goblin Tools（Magic ToDo） | AI 拆步驟，可用「辣度」調整拆多細。網頁免費，App 一次性買斷 | 只負責拆，不幫你挑現在做什麼 |
| 視覺化規劃 | Tiimo | 專為 ADHD 設計，彩色時間軸、倒數計時、AI 拆任務。Pro 約每年 54 美元 | 排行程用的 |
| 視覺化規劃 | Structured | 簡單的時間軸，可以接行事曆。Pro 約每年 20 美元 | 排行程用的 |
| 隨機挑任務 | Modes（iPhone） | 有任務隨機挑選功能 | 沒看到依時間或精力篩選，隨機只是附加功能 |
| 隨機挑任務 | To Do List, Goals & Sorting（iPad） | 隨機挑任務、依預估時間排序 | 同上，**最接近的競品** |
| 依精力挑 | Task Energy Matcher（Android） | 選擇精力高低，建議任務類型 | 不是隨機的 |
| 依精力挑 | Lifestack | 追蹤一天的精力變化，自動排程 | 偏向自動排程 |
| 通用轉盤 | Wheel of Names、Picker Wheel | 轉盤動畫 | 沒有任務管理 |

（價格和功能是 2026-10 查到的資料，可能會變動。）

結論：規劃型 App 要使用者**自己做決定**，而我們的使用者正是**不想做決定**，所以抽選本身就是核心功能。

## 4. 第一版（MVP）功能

### 4.1 加入想做的事

- **只填名稱就能加入**，其他欄位都可以之後再補。記下想法不能變成負擔
- 欄位：
  - **名稱**
  - **分類**：例如鉤織、線上課程、任務、規劃。可以自訂，每個分類有一個顏色
  - **精力類型**：🧠 動腦／✋ 動手／☕ 放鬆
  - **一次大概做多久**：用按鈕選，不用打字。例如 15 分／30 分／1 小時／2 小時／半天
  - **小步驟**（選填）

### 4.2 「需要多久」和「小步驟」兩種都要有

- 「需要多久」很直覺；拆成小步驟可以減少壓力，比較容易輕鬆完成一個階段
- **沒有拆步驟的事**：用「一次做多久」來判斷。做完不會消失，下次還能抽到（例如塔羅課程，一次上 1 小時）
- **有拆步驟的事**：抽選時只會抽到「**下一個還沒做的步驟**」。做完打勾，進度條往前一格，全部做完就跑出完成動畫 🎉
- 每個步驟可以有自己的時間；精力類型預設跟著整件事，但每個步驟也可以另外設定（例如「規劃打工度假」大部分要動腦，但「去拍證件照」是動手）

範例：

```
🧶 整理衣櫃                 [動手]
   ├─ ☐ 冬季外套     30 分
   ├─ ☐ 抽屜整理     15 分
   └─ ☐ 鞋櫃        1 小時
   進度 ▓░░ 0/3

📚 線上課程＿塔羅牌          [動腦]
   （沒拆步驟）一次 1 小時，可重複做
```

### 4.3 抽扭蛋

抽之前先選：

> 我現在有 **[30分] [1小時] [2小時] [半天]**
> 想做 **[都可以] [動腦] [動手] [放鬆]**
> （選填）只從某個分類裡抽
> → 🎰 抽！

- 只會抽到時間夠做、精力類型符合的事
- 扭蛋的顏色代表分類，掉出來之後打開，顯示任務卡片：

```
  ┌─────────────────┐
  │ 🧶 鉤織皮克敏織圖   │
  │ 下一步：選線材     │
  │ ⏱ 30 分 · 動手     │
  │ [開始做] [再抽一次] │
  └─────────────────┘
```

- 第一版**不需要美術設計**：扭蛋是程式畫的彩色圓形，打開的動畫用 CSS 做

### 4.4 抽選規則（加權）

- **越久沒抽到的事，被抽到的機率越高**，避免有些事一直被遺忘
- 具體公式寫程式時再決定，原則是溫和地調整，不能讓某件事每次都被抽到

### 4.5 一直被跳過的事

同一件事**連續被跳過 3 次**，跳出溫和的詢問：

> 🤔 「整理捐贈物資」已經被跳過 3 次了，要怎麼處理？
> - **還是想做**：跳過次數歸零
> - **拆小一點**：可能是事情太大太累人，拆成小步驟比較好開始
> - **先冰起來 🧊**：暫時不出現，放進「冷凍庫」，之後想到再拿出來
> - **不做了**：刪除

一直跳過不一定是不想做，有時候只是事情太大，或是現在還不是時候，所以不要只有「刪除」一個選項。

### 4.6 完成時記錄

- 做完時記錄**花了多久**（預設是預估時間，可以修改）
- 第一版先把資料存起來就好，不一定要做統計畫面。以後做統計功能（例如「這個月學了 8 小時日文」）時，就會有之前的資料可以用

### 4.7 形式

- **PWA**：可以加到手機主畫面、可以離線用，iPhone 和 Android 都能用
- **手機優先**
- 資料存在裝置上，不需要帳號

## 5. 資料結構（草案）

```
想做的事 Item
  id
  名稱 title
  分類 categoryId
  精力類型 energy: 動腦 | 動手 | 放鬆（可以不填）
  一次做多久 duration（分鐘，可以不填）
  狀態 status: 進行中 | 冷凍庫 | 已完成
  小步驟 steps: Step[]（可以是空的）
  上次被抽到的時間 lastPickedAt
  連續被跳過的次數 skipCount
  建立時間 createdAt

小步驟 Step
  id
  名稱 title
  需要多久 duration（分鐘）
  精力類型 energy（沒填就跟著 Item）
  是否完成 done

分類 Category
  id
  名稱 name
  顏色 color

完成紀錄 Log
  id
  itemId
  stepId（如果是完成某個步驟）
  花了多久 minutes
  完成時間 doneAt
```

存取資料的程式碼要獨立成一層（例如 `storage` 模組），之後要加雲端同步時只換掉這一層。

## 6. 技術決定

| 項目 | 決定 | 原因 |
|---|---|---|
| 形式 | PWA | 做一份就全平台都能用，丟網址就能請朋友試用，不用審核和上架費（Apple 開發者帳號一年 99 美元） |
| 以後上架 | 用 Capacitor 之類的工具包裝 | 同一份程式不用重寫 |
| 資料 | 第一版存在裝置上 | 不需要帳號，打開就能用；「跨裝置同步」以後可以當付費功能 |
| 上線 | GitHub Pages | repo 是 Public，免費 |
| API 金鑰 | 第一版不需要 | 以後的雲端同步、AI 功能才需要，金鑰不能直接寫在前端程式裡 |
| 文字 | 集中管理 | App 名稱可能會改，以後也可能要多語系 |
| 框架 | 尚未決定 | 建議保持簡單，例如 Vite + TypeScript + PWA 外掛 |

## 7. 階段規劃

1. **第一階段**：做出 PWA，自己用 2～3 週，看看哪裡卡、哪裡好用
2. **第二階段**：丟網址給幾個朋友試用，收集回饋
3. **第三階段**：如果真的有人持續在用，再加帳號、同步、付費功能，考慮上架

## 8. 以後可以加的功能

| 功能 | 說明 | 需要美術嗎 |
|---|---|---|
| 完成罐 | 每做完一件事，就有一顆扭蛋掉進罐子裡，看著罐子慢慢裝滿很療癒 | ❌ |
| 統計回顧 | 「這個月學了 8 小時日文」 | ❌ |
| 徽章、角色、扭蛋機造型 | 蒐集要素 | ✅ 需要找插畫家 |

## 9. 收費想法（還沒驗證）

| 免費 | 付費候選 |
|---|---|
| 清單、扭蛋、時間／精力篩選、小步驟 | ☁️ 跨裝置同步 |
| | ✨ **AI 幫你拆小步驟**：輸入「規劃日本打工度假」，自動拆成 15 分鐘的小步驟。最符合這個 App 的核心概念 |
| | 📊 時間統計、回顧 |
| | 🎨 扭蛋機造型、主題、角色 |

參考：Goblin Tools 是一次性買斷，Tiimo 和 Structured 是訂閱制。

## 10. 還沒決定的事

- 時間按鈕的選項（15 分／30 分／1 小時／2 小時／半天？）
- 預設有哪些分類、各用什麼顏色
- 加權的具體公式
- 「開始做」之後要不要有計時器，還是只在完成時記錄時間
- 第一版要不要有匯出／匯入備份功能（資料只存在一台裝置上，清除瀏覽器資料就會不見）
